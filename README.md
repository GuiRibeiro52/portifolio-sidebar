# Portfolio Sidebar

A modern, responsive portfolio website with a sidebar navigation, built with React, Vite, and Tailwind CSS.

![Portfolio Screenshot](public/LogotipoGR.png)

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to all screen sizes with a collapsible sidebar for mobile devices
- **Multilingual Support**: Available in English and Portuguese with automatic language detection
- **Animated Transitions**: Smooth page transitions and animations using Framer Motion
- **Contact Form**: Integrated with EmailJS for easy contact form submission
- **SEO Optimized**: Includes meta tags and structured data for better search engine visibility
- **Accessibility**: Built with accessibility in mind, including proper ARIA attributes and keyboard navigation

## 📋 Pages

- **Home**: Introduction and hero section
- **About**: Personal information, skills, and background
- **Works**: Portfolio of projects with detailed modal views
- **Contact**: Contact form and social media links

## 🛠️ Technologies

- **React**: Frontend library for building user interfaces
- **Vite**: Next-generation frontend tooling
- **Tailwind CSS**: Utility-first CSS framework
- **React Router**: For navigation and routing
- **i18next**: Internationalization framework
- **Framer Motion**: Animation library
- **EmailJS**: Email service for contact form
- **React Helmet Async**: Document head manager for SEO
- **Jest**: Testing framework

## 🔧 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portifolio-sidebar.git
   cd portifolio-sidebar
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in the root directory with your EmailJS credentials:
   ```
   VITE_EMAILJS_SERVICE_ID=your_service_id
   VITE_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_EMAILJS_PUBLIC_KEY=your_public_key
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Build

To build the project for production:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

## 🧪 Testing

Run tests with Jest:

```bash
npm test
```
